# Metrics Baseline

This document defines baseline metrics for Phase 0 and Phase 1 implementation work.

## Security

- **MTTP-C (Mean Time to Patch - Critical):** Average elapsed time from critical vulnerability triage to patch release.
- **Target:** less than or equal to 72 hours.

## Compatibility

- **Break/Fix Time:** Elapsed time between upstream compatibility breakage detection and verified fix release.
- **Target:** less than or equal to 5 business days.

## Onboarding

- **First-Run Completion Rate:** Percentage of new users completing onboarding without abandoning the flow.
- **Target:** 80% or higher.

## Model Search

- **First Model Works Rate:** Percentage of users who can successfully use a model selected from search on the first attempt.
- **Target:** 85% or higher.

## Reporting Cadence

- Weekly internal review for active releases.
- Monthly summary posted with release notes when significant security or compatibility work ships.
