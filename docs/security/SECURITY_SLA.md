# Vulnerability Triage SLA

## Severity Definitions and SLA

### Critical
- Triage: within 24 hours
- Patch available: within 72 hours

### High
- Triage: within 3 days
- Patch available: within 7 days

### Medium
- Triage: within 7 days
- Patch scheduled: next regular release cycle

### Low
- Triage: within 14 days
- Patch scheduled: backlog with risk review

## Process

1. Intake and initial severity assignment.
2. Reproduction and blast-radius assessment.
3. Mitigation/patch implementation.
4. Validation through tests and targeted checks.
5. Release and disclosure notes.
